# CLAUDE.md — Fuelo

Standing memory of the **Fuelo** project. Fuelo is a nutrition-discovery app for
independent restaurants: browse spots on a map, open a restaurant, and see
AI-estimated calories, protein and macros for each dish. Tagline in the header:
_"Enjoy eating out, fuelled by healthy decisions."_

This file documents the project so future sessions have context. **Do not change
features unless asked** — this repo is Lovable-generated and syncs two-way with
GitHub.

## Database (Supabase / Postgres)

Source of truth: `supabase/migrations/`. Six tables in `public`. All have
Row Level Security **enabled**. Read tables are publicly readable; the two lead
tables are insert-only for the public.

### `restaurants`  — the venues on the map

| Column | Type | Notes |
| --- | --- | --- |
| `id` | uuid PK | `gen_random_uuid()` |
| `name` | text | NOT NULL |
| `cuisine` | text | nullable — legacy freeform text, **kept for now** |
| `cuisines` | text[] | NOT NULL default `'{}'` — structured taxonomy tags (a restaurant can have several). Source of truth for the cuisine filter + trending tiles. Fixed vocabulary in `src/lib/cuisines.ts` (`CUISINE_TAGS`); added in migration `20260714093000_add_restaurant_cuisines`. |
| `address` | text | nullable |
| `area` | text | nullable (shown with a pin icon, e.g. "Dalston") |
| `latitude` | double precision | nullable (map pin) |
| `longitude` | double precision | nullable (map pin) |
| `image_url` | text | nullable |
| `verified` | boolean | NOT NULL default `false` → "Verified Nutrition" |
| `created_at` | timestamptz | default `now()` |

RLS: **public SELECT** (`anon`, `authenticated`). `service_role` full access.

### `menus`  — a restaurant's menu(s)  _(not in the original brief, but exists)_

| Column | Type | Notes |
| --- | --- | --- |
| `id` | uuid PK | |

| `name` | text | NOT NULL |
| `menu_type` | text | nullable |
| `created_at` | timestamptz | default `now()` |

RLS: **public SELECT**. Indexed on `restaurant_id`.

### `menu_items`  — dishes with nutrition ranges

| Column | Type | Notes |
| --- | --- | --- |
| `id` | uuid PK | |
| `menu_id` | uuid FK → menus(id) | nullable, ON DELETE CASCADE |
| `restaurant_id` | uuid FK → restaurants(id) | NOT NULL, ON DELETE CASCADE |
| `name` | text | NOT NULL |
| `category` | text | nullable (grouped/ordered on the restaurant page) |
| `description` | text | nullable |
| `price_gbp` | numeric | nullable (rendered as £) |
| `calories_min` / `calories_max` | integer | nutrition range (kcal) |
| `protein_min` / `protein_max` | numeric | grams |
| `carbs_min` / `carbs_max` | numeric | grams |
| `fat_min` / `fat_max` | numeric | grams |
| `dietary_tags` | text[] | default `'{}'` (e.g. vegan, GF) |
| `tag_source` | text | CHECK in (`menu-stated`, `AI-estimated`) |
| `confidence` | numeric | 0–1, drives the ConfidenceRing |

| `created_at` | timestamptz | default `now()` |

RLS: **public SELECT**. Indexed on `restaurant_id` and `menu_id`.
Nutrition ranges render via `formatRange()` in `src/lib/fuelo-types.ts` (shows
`min–max`, `~x` if only one bound, single value if equal).

### `user_waitlist`  — email capture (consumer waitlist)

| Column | Type | Notes |
| --- | --- | --- |
| `id` | uuid PK | |
| `email` | text | NOT NULL |
| `created_at` | timestamptz | default `now()` |

RLS: **public INSERT only**, with a WITH CHECK enforcing a valid email regex and
`length(email) <= 255`. No public SELECT. Written by `WaitlistBanner.tsx`.

### `restaurant_leads`  — email capture (restaurant "claim" leads)

| Column | Type | Notes |
| --- | --- | --- |
| `id` | uuid PK | |
| `email` | text | NOT NULL |
| `restaurant_name` | text | nullable (≤ 200 chars) |
| `created_at` | timestamptz | default `now()` |

RLS: **public INSERT only**, WITH CHECK enforcing email regex, `email ≤ 255`,
and `restaurant_name` null or ≤ 200 chars. No public SELECT. Written by

> **"Saved" is not a table.** Saved restaurants live only in browser

> no user-auth / accounts flow yet.

## Design conventions — cream + green

The theme is defined **CSS-first** in `src/styles.css` using OKLCH tokens
(Tailwind v4 `@theme inline` + `:root` / `.dark`). Colors are referenced through
CSS variables and Tailwind semantic classes (`bg-background`, `text-primary`,
`bg-card`, …) — **do not hard-code hex**; extend the tokens in `styles.css`.

**Palette (light mode):**

- **Cream background** — `--background: oklch(0.985 0.012 90)` (warm off-white).
  Foreground near-black `oklch(0.18 0.01 90)`.
- **Fresh green primary** — `--primary: oklch(0.62 0.17 148)` (buttons, logo,
  active states, links, the map pins `#16a34a`, the focus `--ring`).
- **Cards** are pure white (`--card: oklch(1 0 0)`) on the cream background.
- **Green accent** — `--accent: oklch(0.94 0.05 148)` with darker green accent
  foreground; used for dietary-tag pills and hover states.
- **Secondary / muted** — soft warm greys (`oklch(0.955 0.012 90)`).
- **Destructive** — red `oklch(0.6 0.22 27)` for errors.
- A **dark mode** (`.dark`) mirror exists with the same green identity.

**Shape & elevation:**

- Rounded, soft, mobile-first. Base radius `--radius: 1rem`; cards/inputs use
  `rounded-2xl`, pills/buttons `rounded-full`.
- Two custom shadows — `--shadow-card` (resting) and `--shadow-float`
  (hover/floating), both tinted with a green hue. Use
  `shadow-[var(--shadow-card)]` / `shadow-[var(--shadow-float)]`.

**Typography:**

- **Inter** (`--font-sans` / `--font-display`), loaded from Google Fonts in
  `__root.tsx`. Headings are bold/extrabold with tight tracking
  (`-0.02em`). Small uppercase labels use `text-[11px] uppercase tracking-widest
  text-muted-foreground`.

**Map styling (Leaflet, in `styles.css`):**

- CARTO **light** basemap, tiles nudged warm via
  `filter: sepia(0.10) saturate(1.05) brightness(1.02)` to match the cream theme.
- Custom **green teardrop pins** (`.fuelo-pin`, active variant enlarges + white
  outline). User location is a **blue dot** (`.fuelo-user-dot`, `#2563eb`).

**Verification / confidence language (consistent across the app):**

- Verified data → green, "Restaurant Verified" / "Verified Nutrition" + check.
- Estimated data → "AI Estimated", with a `ConfidenceRing` whose fill/label
  ("Good / Fair / Rough estimate") and color come from the `confidence` value.
- Every nutrition surface carries the disclaimer: AI-estimated, not a guarantee,
  check with the restaurant for allergens.

## Conventions & gotchas for future work

- **Don't edit generated files:** `src/routeTree.gen.ts`,
  `src/integrations/supabase/client.ts`, `src/integrations/supabase/types.ts`.
- **New data:** fetch in a route `loader` + `useSuspenseQuery`, matching
  `index.tsx` / `restaurants.$id.tsx`.
- **New DB changes:** add a migration under `supabase/migrations/` (don't mutate
  existing ones); keep RLS in mind (public tables are read-only to `anon`).
- **Styling:** add/adjust tokens in `src/styles.css`; use semantic Tailwind
  classes and the shadow variables; keep the cream + green identity.
- **Two-way sync:** commit small, keep `main` green, never rewrite history.
